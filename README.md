# Переформулировка разговорных запросов для поиска подкастов

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/LOMELLO/media_query_rewriting/blob/main/media_query_rewriting.ipynb)

Rule-based исследование: как контекст диалога и разговорная формулировка влияют на поиск подкастов. Без обучения моделей и без LLM.

## Данные

- 78 русскоязычных подкастов из Apple Podcasts Search API и RSS.
- 30 запросов пяти типов: настроение/ситуация, разговорный/неполный, уточнение с контекстом, ограничения/исключения, no-op.
- Поиск: TF-IDF по символьным n-граммам, cosine similarity и жёсткие фильтры.

## Запуск

Открыть ноутбук в Colab или выполнить локально:

```bash
pip install -r requirements.txt
jupyter notebook media_query_rewriting.ipynb
```

## Результаты

- Hit@5: `0.900` до и `0.967` после переформулировки.
- P@5: `0.523` до и `0.790` после.
- Для уточнений с контекстом P@5 растёт с `0.225` до `0.800`.
- Тема и ограничения сохранены в `30/30` запросов; `5/5` no-op остаются без изменений.

Основное ограничение — лексический поиск: запрос `n28` про психологию сна не выводит sleep-подкасты в топ. Подробности и анализ — в ноутбуке.
